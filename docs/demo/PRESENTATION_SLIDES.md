# Slide 2: Why Atlas?
- Custom Inverted Index BM25 Engine (Zero dependence on Lucene/Elasticsearch/Solr).
- 10-Mode Reasoning Engine (Tree-of-Thoughts, ReAct, Re-Planning).
- Long-Term Memory with Ebbinghaus Forgetting Curve Decay.
- AIOS Autonomous Mission Control & Self-Healing Recovery.
