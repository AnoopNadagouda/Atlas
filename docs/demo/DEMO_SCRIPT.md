# Atlas v6.0.0 — 10-Minute Live Demonstration Script

## Overview
This script guides a presenter through a 10-minute demonstration of Atlas v6.0.0, highlighting the Custom Inverted Index BM25 search engine, AI Multi-Agent Core, DAG Workflows, Long-Term Memory decay, 10-mode Reasoning Engine, and AIOS Orchestration.

---

## ⏱️ Walkthrough Schedule

### 00:00 - 02:00: Platform Architecture & Landing Page
- Open React UI at `http://localhost:3000`.
- Highlight the Antigravity-inspired dark theme, glassmorphic UI, glowing cards, and live system metrics.
- Navigate to `/architecture` to showcase the 16 production pipeline diagrams.

### 02:00 - 04:00: Search Studio & BM25 Keyword Engine
- Navigate to `/search`.
- Execute query `"distributed inverted index"`.
- Demonstrate custom inverted index segment fetching, BM25 scoring, and vector embedding re-ranking latency (< 14ms).

### 04:00 - 06:00: AIOS Master Dashboard & Mission Control
- Navigate to `/aios` -> Mission Control.
- Formulate a new autonomous mission: `"Global Enterprise Financial Risk Indexing"`.
- Click **Execute Mission**. Observe live agent dispatching, DAG step triggering, and real-time timeline logging.

### 06:00 - 08:00: Multi-Mode Reasoning & AI Memory Graph
- Navigate to `/reasoning`. Showcase Tree of Thoughts (ToT) reasoning session with Critic evaluation and self-reflection.
- Navigate to `/memory`. Showcase Ebbinghaus memory decay curves and vector context consolidation.

### 08:00 - 10:00: Interactive API Explorer & Production Helm/K8s Setup
- Navigate to `/api-explorer`.
- Demonstrate sending live REST requests across `/api/v23/orchestrator/*`.
- Wrap up by showing Docker Compose and Kubernetes Helm chart deployment capabilities.
