# Atlas Coding Standards

## Java 21 Code Conventions
- Follow Clean Code & SOLID design principles.
- Use Java 21 features (pattern matching, records, sealed classes, virtual threads where applicable).
- Maintain immutable DTOs and clear Separation of Concerns.
- All public REST endpoints must include OpenAPI Swagger annotations.

## React & TypeScript Conventions
- Strict TypeScript typing (`noImplicitAny`, strict null checks).
- Functional React components with custom hooks.
- Glassmorphic CSS tokens with dark theme styling.
