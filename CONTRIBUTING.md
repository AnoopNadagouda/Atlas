# Contributing to Atlas

Thank you for your interest in contributing to **Atlas: Enterprise Distributed AI Search Platform**!

## Guidelines
1. **Fork & Branch**: Create a feature branch off `main`.
2. **Code Quality**: Follow Java 21 and Spring Boot best practices. Clean Architecture and DDD principles must be preserved.
3. **Testing**: Run `mvn clean test` across all 14 modules before submitting pull requests. Ensure 100% test pass rate.
4. **Pull Requests**: Submit PRs with detailed descriptions of changes, architecture impact, and test evidence.
