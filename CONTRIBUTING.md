# Contributing to Atlas

Thank you for your interest in contributing to **Atlas**, the open-source Enterprise AI Search Engine Platform & Autonomous AIOS!

## How to Contribute

1. **Fork the Repository** on GitHub.
2. **Create a Feature Branch** (`git checkout -b feature/my-amazing-feature`).
3. **Commit your Changes** using Conventional Commits (`git commit -m 'feat(agent): add new tool capability'`).
4. **Push to the Branch** (`git push origin feature/my-amazing-feature`).
5. **Open a Pull Request** against the `main` branch.
